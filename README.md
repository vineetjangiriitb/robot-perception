# Robust + Uncertainty-Aware Robot Perception

An uncertainty-aware **RT-DETR** detector for humanoid robot components (arm, leg,
torso, head, sensor) that degrades **gracefully** under real-world image
corruptions and outputs **calibrated uncertainty** alongside every prediction.

## Key finding

*(Generated by `07_analysis.ipynb` from the result JSONs.)*
Corruption-aware augmentation improves mean performance under corruption (mPC)
without sacrificing clean accuracy; MC Dropout provides calibrated uncertainty
that increases monotonically with corruption severity; conformal prediction at
ε = 0.05 provides distribution-free ≥95% coverage guarantees.

## Methods

- **Dataset** — humanoid robot components, 5 classes, YOLO-format annotations
  (≥300 images; train/val/test/calibration splits)
- **Architecture** — RT-DETR-L, fine-tuned from COCO pretrained weights
- **Corruption benchmark** — ImageNet-C methodology, 5 corruption types
  (gaussian noise, motion blur, gaussian blur, brightness, occlusion) × 5
  severities = 25 scenarios
- **Robust training** — corruption-aware albumentations augmentation
- **Uncertainty** — MC Dropout, N=30 stochastic forward passes; decoder dropout
  injected at `p=0.1` (stock RT-DETR ships dropout at `p=0.0`)
- **Conformal prediction** — ε=0.05, threshold from a 100-image calibration set

## Setup & usage

This project runs on **Google Colab free tier (T4 GPU)** with data and models
persisted in Google Drive at `/content/drive/MyDrive/robot-perception/`.

1. In Colab: `Runtime → Change runtime type → T4 GPU`.
2. Run the notebooks in order, starting with `00_colab_setup.ipynb` (run once
   per session — installs packages, mounts Drive, creates the folder structure).
3. Each notebook ends with a completion checklist; do not advance to the next
   phase until its metric targets are met.

For local development:

```bash
pip install -r requirements.txt
```
